# MagicVilla API

A RESTful Web API built with **ASP.NET Core** and **Entity Framework Core** for managing villa listings with full CRUD support, partial updates via JSON Patch, and SQL Server persistence.

---

## Features

- **Full CRUD Operations**: Create, Read, Update, and Delete endpoints.
- **Partial Updates**: Implemented using HTTP `PATCH` and `JsonPatchDocument` (`Newtonsoft.Json`).
- **Database Integration**: Code-First approach using **Entity Framework Core** and **SQL Server**.
- **Interactive Documentation**: Integrated **Swagger / OpenAPI** UI for endpoint testing.

---

## Tech Stack

- **Framework**: .NET 8 / ASP.NET Core Web API
- **ORM**: Entity Framework Core
- **Database**: Microsoft SQL Server
- **API Testing**: Postman / Swagger UI
